# ER Queueing & Resource Allocation Simulator (Cloud Edition)
### Next.js + Vercel + Supabase 기반 병원 응급실 인력 및 자원 배치 최적화 시뮬레이터

불확실한 환자 유입 상황에서 의료진(의사, 간호사) 수와 병상 배치가 환자 대기시간 및 가동률에 미치는 영향을 정량적으로 분석하고 실시간 시각화하는 클라우드 웹 기반 의사결정 지원 시스템(DSS)입니다.

---

## 1. 클라우드 아키텍처 및 기술 스택

- **Frontend & App Framework**: Next.js 16 (App Router, React 19, TypeScript)
- **Styling & Components**: Tailwind CSS, Lucide React (병원 응급의료센터 Navy/Blue 대시보드 테마)
- **Visualization**: Recharts (시계열 복합 차트, 이중축 Trade-off 곡선, 비교 막대 차트, 대기시간 히스토그램)
- **Queueing Theory Engine**: Analytical M/M/s (Erlang-C 공식, 수치 안정화 포아송 누적 확률 계산)
- **Simulation Engine**: Pure TypeScript Discrete-Event Simulation (DES, 최소 힙 이벤트 캘린더, 시간가중 적분)
- **Cloud Database**: Supabase (PostgreSQL, 실시간 시나리오 영속화 및 RLS 지원, LocalStorage 하이브리드 Fallback 탑재)
- **Deployment & Hosting**: Vercel (Edge Network CI/CD 배포)

---

## 2. 주요 기능

1. **동적 파라미터 제어 (실시간 반응형 사이드바)**
   - 환자 도착률 ($\lambda$, 0.5 ~ 12.0명/시간, step 0.5)
   - 의사 처리율 ($\mu_d$) 및 당직 의사 수 ($s_d$)
   - 간호사 처리율 ($\mu_n$) 및 당직 간호사 수 ($s_n$)
   - 병상 수 제어 및 병상 무제한 모드
   - 추천 데모 프리셋 원클릭 지원 (A. 정상 운영, B. 병목 주의, C. 과부하 불안정, D. 의사 증원 최적화)
2. **실시간 성능 비교 대시보드 (KPI Cards & 표)**
   - 가동률 ($\rho$), 대기시간 ($W_q$), 체류시간 ($W$), 대기환자수 ($L_q$), 재원환자수 ($L$)
   - M/M/s 이론치 vs DES 시뮬레이션 실측치 오차율 및 95% 신뢰구간
3. **병목 알림 & 안전성 경고 시스템**
   - $\rho < 0.85$: 정상 안정
   - $0.85 \le \rho < 1.0$: 병목 주의 (권장 최소 인력 실시간 계산)
   - $\rho \ge 1.0$: 시스템 과부하 및 불안정 경고
4. **인터랙티브 시각화 차트**
   - 시간대별 대기 환자 수 및 병상 점유율 추이 복합 에어리어 차트
   - 대기시간 vs 가동률 이중 y축 Trade-off 최적화 곡선 및 목표 대기시간 기준선
   - 환자별 대기시간 구간 분포 히스토그램
5. **Supabase 클라우드 데이터베이스 연동 및 내보내기**
   - 클라우드 PostgreSQL에 시뮬레이션 시나리오 저장 및 조회
   - 환자별 타임스탬프 원시 데이터 CSV 다운로드
   - 실험 파라미터 및 요약 통계 JSON 다운로드

## 3. Supabase 설정 (SQL)

Supabase 대시보드(SQL Editor)에서 `supabase/schema.sql` 내용을 실행하여 테이블을 생성합니다:

```sql
CREATE TABLE IF NOT EXISTS public.simulation_runs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    scenario_name TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    arrival_rate REAL NOT NULL,
    doctor_mu REAL NOT NULL,
    num_doctors INT NOT NULL,
    nurse_mu REAL NOT NULL,
    num_nurses INT NOT NULL,
    num_beds INT,
    sim_hours REAL NOT NULL,
    doctor_rho REAL,
    doctor_wq_min REAL,
    doctor_w_min REAL,
    doctor_lq REAL,
    doctor_l REAL,
    status TEXT NOT NULL
);
ALTER TABLE public.simulation_runs ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read access" ON public.simulation_runs FOR SELECT TO anon, authenticated USING (true);
CREATE POLICY "Allow public insert access" ON public.simulation_runs FOR INSERT TO anon, authenticated WITH CHECK (true);
```
